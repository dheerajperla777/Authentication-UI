Authentication UI

About

A simple login interface built using HTML, CSS, and JavaScript.

Features

- Email and password fields
- Password visibility toggle
- Basic form validation
- Responsive login layout
- User-friendly interface

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.

Important Note

This is a frontend demonstration only. It does not provide real authentication or create user accounts.

Project Purpose

To practice form handling, input validation, and interactive UI development.
